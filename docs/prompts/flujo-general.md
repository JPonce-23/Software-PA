# Flujo completo de prompts para Codex

## Orden general

```text
Prompt 1: diseñar propuesta
        ↓
Resolver posibles bloqueos del diseño
        ↓
Prompt 2: evaluar e implementar
        ↓
Resolver posibles bloqueos de implementación
        ↓
Prompt 3: auditar implementación
        ↓
Corregir o cerrar
```
