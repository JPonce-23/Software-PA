Actúa como arquitecto de software senior.

No implementes código.

## Tarea exacta

1. Lee `ESTADO_PROYECTO.md`.
2. Revisa la propuesta rechazada y el reporte de evaluación.
3. Extrae todos los gates fallidos.
4. Identifica las causas raíz.
5. Clasifica cada problema como:

   * funcional;
   * datos;
   * seguridad;
   * arquitectura;
   * migración;
   * compatibilidad;
   * pruebas.
6. Conserva las partes válidas.
7. Sustituye únicamente las partes rechazadas.
8. Genera una propuesta corregida.
9. Evalúa nuevamente todos los gates.
10. No implementes.
