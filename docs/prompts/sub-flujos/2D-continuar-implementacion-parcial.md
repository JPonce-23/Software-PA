# PROMPT 2D — CONTINUAR UNA IMPLEMENTACIÓN PARCIAL

Actúa como arquitecto y desarrollador full-stack senior.

La implementación anterior quedó parcial.

No reinicies el trabajo ni repitas cambios ya aplicados.

## Tarea exacta

1. Lee `ESTADO_PROYECTO.md`.
2. Revisa:

   * propuesta aprobada;
   * reporte de implementación;
   * estado de Git;
   * diff;
   * archivos nuevos;
   * pruebas.
3. Clasifica cada incremento como:

   * terminado;
   * parcial;
   * no iniciado;
   * fallido;
   * bloqueado.
4. Verifica directamente los cambios existentes.
5. No confíes únicamente en el reporte anterior.
6. Identifica el primer incremento incompleto.
7. Continúa desde ese punto.
8. No sobrescribas trabajo correcto.
9. Ejecuta pruebas después de cada incremento.
10. Revisa el diff y los archivos fuera de alcance.
11. Detente ante decisiones funcionales no resueltas.
12. Actualiza `ESTADO_PROYECTO.md` únicamente con trabajo validado.
13. No hagas commit ni push.

## Formato de salida

| Incremento | Estado | Evidencia | Acción |

Después incluye:

1. Cambios realizados.
2. Pruebas ejecutadas.
3. Riesgos restantes.
4. Estado de la documentación.
5. Veredicto.

Estados permitidos:

* Implementación todavía parcial.
* Implementación bloqueada.
* Implementación completa pendiente de validación.
* Implementación completa y validada.

Cuando quede completa, ejecuta el Prompt 3.
