Quiero desarrollar un sistema, que será de seguimiento para un proyecto ferroviario para la Procuraduría Agraria que se encargue de dar seguimiento a la liberación de derechos de la propiedad social nos interesa que sea un tipo dashboard/reporteador para mostrar:

Cuantos convenios individuales se han formalizado.
Cuantos convenios de uso común se han formalizado.
Cuantos ejidos, comunidades hay.
Cuantas superficies se han liberado tanto de derechos individuales como de derechos uso común con su ubicación y los metros cuadrados liberados (área).

El avance general se pretende que sea en una grafico de pastel o circular principalmente en donde se muestre el porcentaje liberado en metros cuadrados y esto que se refleje para cada trazo o tramo que seguirá el paso del tren, ya que serán varios tramos, un tramo representa cada uno de los tramos principales que conforman el proyecto ferroviario. Constituye la unidad geográfica y operativa de mayor nivel dentro del sistema, para el seguimiento del derecho de vía.

Estos datos eran recopilados por personas y la base de datos está principalmente en Excel, entonces pretendo que el sistema tenga ciertos tipos de usuarios para que este pueda ser atendido por varias personas para el llenando de la información, y para que otro tipo de usuario que sería el final pueda ir viendo el avance, el reporte de todo lo que se está trabajando.
